## Projetos em destaque

### 🚚 Análise Logística com Python

Análise de uma base fictícia com **500 entregas**, desenvolvida para acompanhar prazos, custos de frete, ocorrências e desempenho de transportadoras.

**Principais resultados:**

* 500 entregas analisadas;
* 65% das entregas realizadas no prazo;
* R$ 239.967,02 de custo total de frete;
* Comparação de custos e desempenho entre transportadoras;
* Geração automática de indicadores, tabelas e gráficos.

**Tecnologias:** Python, Pandas e Matplotlib.

🔗 [Acessar o projeto](https://github.com/vitorassis-tech/analise-logistica-python)

---

### 📊 Dashboard Logístico no Power BI

Dashboard desenvolvido para analisar uma operação fictícia com **1.000 fretes**, incluindo custos, prazos, transportadoras, regiões e ocorrências.

**Principais resultados:**

* 1.000 fretes analisados;
* R$ 914.455,95 de custo total de frete;
* 81,50% das entregas realizadas no prazo;
* Medidas e indicadores desenvolvidos em DAX;
* Dashboard com filtros por período, transportadora e região.

**Tecnologias:** Power BI, Power Query e DAX.

🔗 [Acessar o projeto](https://github.com/vitorassis-tech/dashboard-logistico-power-bi)

---

### 🗄️ Banco de Dados Logístico com SQL

Banco de dados relacional desenvolvido para simular o controle de produtos, estoque, clientes, pedidos, entregas e transportadoras.

**Principais entregas:**

* Criação do banco e das tabelas;
* Definição de chaves primárias e estrangeiras;
* Modelagem dos relacionamentos;
* Consultas para análise de estoque;
* Indicadores de faturamento e desempenho logístico;
* Diagrama criado no MySQL Workbench.

**Tecnologias:** SQL, MySQL e MySQL Workbench.

🔗 [Acessar o projeto](https://github.com/vitorassis-tech/banco-dados-logistica-sql)
